Privacy & Cookies Policy

Last updated: November 2026

FlowingBot is a static website hosted on Cloudflare Pages. There's no Google Analytics, no Meta Pixel and no marketing tracking scripts. I don't profile visitors and I don't sell data.

Still, a small amount of technical data is processed to keep the site secure and working. Here's what and why.

1. Hosting and network (Cloudflare)

This site is served through Cloudflare Pages and the Cloudflare network. Like any hosting and CDN provider, Cloudflare processes basic request information to deliver pages, protect the site from abuse and attacks, and keep the service running.

  • Data processed: IP address, browser type (User-Agent), requested pages, timestamps and other standard request metadata.
  • My own logs: I don't run my own server for this site and I don't keep my own logs of visits. This data is handled by Cloudflare under its own policies, including how long it is kept. See the Cloudflare Privacy Policy.
  • Where: Cloudflare operates servers around the world, so your request may be handled outside your country.
  • Cookies: Cloudflare may set technical security cookies, for example to tell real visitors from bots (such as __cf_bm) or to remember that you passed a security check (such as cf_clearance). They exist for security and are not used for advertising. More details in the Cloudflare cookies documentation.

2. Blog comments (Giscus)

The comments under articles are powered by Giscus, which uses the GitHub Discussions API. That lets me offer comments without running a user database.

  • Reading articles: the Giscus script talks to GitHub servers to load existing comments.
  • Posting comments: sign-in is handled directly by GitHub. I never see or store your credentials. The text of your comment is stored publicly in the site's GitHub repository.
  • Cookies: Giscus and GitHub may use technical and session cookies for authentication and state. For details, see the GitHub Privacy Statement.

3. Third-party fonts

The site uses Google Fonts to render text correctly. When your browser requests them, your IP address is briefly visible to Google servers. More details in the Google Fonts Privacy FAQ.

4. Contact

If you write to info@flowingbot.com, I use your email address and the content of your message only to reply to you.

5. Links to other sites

Some pages link to external sites, such as GitHub repositories and project docs hosted on GitHub Pages. Those sites have their own privacy policies.

6. Your rights

Depending on where you live (for example under the GDPR) you have rights over your personal data, including access, correction and deletion. Since I don't keep user profiles or my own logs, the only identifiable information I might hold is an email thread. Data processed by Cloudflare, Google or GitHub is covered by their own policies, and you can exercise your rights with them too.

For any privacy question, write to info@flowingbot.com.
